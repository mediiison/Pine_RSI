# RSI Confluence — индикатор для TradingView (Pine Script v5)

Индикатор на график цены, который объединяет **4 независимых сигнала** на основе RSI и MACD и подсвечивает бары, где они совпадают.

- **4/4** сигнала совпали → бар подсвечивается фоном (лонг — зелёный, шорт — красный)
- **3/4** сигнала → маленький крестик над/под баром
- На все случаи есть алерты: `4/4 LONG`, `4/4 SHORT`, `3/4 LONG`, `3/4 SHORT`

## Как работает

| # | Сигнал | Лонг | Шорт |
|---|--------|------|------|
| 1 | **Ultimate RSI** — возможные дивергенции RSI (регулярные и скрытые) + зоны перекупленности/перепроданности | бычья дивергенция или RSI < 30 (текущий/предыдущий бар) | медвежья дивергенция или RSI > 70 |
| 2 | **RSI-осциллятор** — RSI(hl2, 7), растянутый в диапазон −100…100 и сглаженный KAMA | значение < 0 | значение > 0 |
| 3 | **RSI-пивоты** — экстремумы RSI(14) и дивергенции в окне 90 баров | бычья дивергенция или pivot low | медвежья дивергенция или pivot high |
| 4 | **MACD-дивергенции** — пивоты гистограммы MACD(12, 26, 9) против цены | бычья дивергенция гистограммы | медвежья дивергенция гистограммы |

Сигналы суммируются отдельно для лонга и шорта (`long_total`, `short_total`, от 0 до 4).

### Дополнительно

- **Панель Reverse RSI** — справа от последнего бара показывает, при какой цене RSI достигнет уровней 70 / 50 / 30 и пересечёт свою EMA.
- **Линии поддержки/сопротивления по RSI** (по умолчанию выключены).
- Точечные линии возможных дивергенций рисуются прямо на графике.

## Установка

1. Открой TradingView → **Pine Editor** (внизу графика).
2. Скопируй содержимое [`src/rsi_confluence.pine`](src/rsi_confluence.pine).
3. Вставь в редактор → **Add to chart**.
4. Для алертов: **Alert** → Condition: `Ultimate RSI` → выбери `4/4 LONG` / `4/4 SHORT` / `3/4 ...`.

## Основные настройки

| Группа | Параметр | По умолчанию |
|--------|----------|--------------|
| RSI Price Prediction | Price 1 / 2 / 3 (уровни RSI) | 70 / 50 / 30 |
| RSI settings | Type / Length / Source | Wilder / 14 / close |
| RSI Divergences | Left/right bars пивота | 3 / 3 |
| RSI Divergences | Maximum lookback bars | 60 |
| Осциллятор | RSI Length / MA Length / MA Type | 7 / 4 / KAMA |
| Пивоты RSI | Div lookback period | 90 |
| MACD | Fast / Slow / Signal | 12 / 26 / 9 |
| MACD | Pivot length | 5 |
